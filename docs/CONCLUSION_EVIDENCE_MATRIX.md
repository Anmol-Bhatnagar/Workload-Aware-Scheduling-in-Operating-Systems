# Conclusion-Evidence Traceability Matrix

Every claim in the project conclusions is directly anchored to empirical runs, saved tables, and concrete metric values.

| Claim ID | Scientific Claim | Supporting Run Groups / Data | Artifact / Table Reference | Contradictory Evidence | Confidence & Limitations |
|---|---|---|---|---|---|
| **CLM-01** | No single classical policy dominates across all metrics (H1 supported). | 3,000 policy evaluations across 500 scenarios in `results/runs/`. | `results/tables/cpu_policy_summary.csv` | None across the 5 tested workload families. | High; RR_Q2 achieves lowest response (5.74t) but 4x context switches (111); SJF achieves lowest wait (75.36t). |
| **CLM-02** | Workload-aware Decision Tree achieves lower composite cost than fixed RR_Q5 on unseen workloads (H2 supported). | 75 held-out scenarios (15% test split) strictly excluded from model training. | `results/tables/ml_evaluation_test.json` | In 4.0% of test scenarios, RR_Q5 matched or had equal/lower cost. | High; ML achieves 0.2088 average cost vs 0.4348 for RR_Q5 (52% cost reduction). Bootstrap 95% CI: [0.1943, 0.2549]. |
| **CLM-03** | ML Recommender is not universally superior to Best Fixed baseline under all weightings (H3 supported). | Primary vs alternative weight sensitivity comparison on 500 scenarios. | `results/tables/sensitivity_analysis.json` | Under primary weights, Best Fixed (SJF) achieves 0.2086 vs ML 0.2088 (essentially equal). Under alternative weights, ML achieves 0.2469, beating Best Fixed (0.2515). | High; Value of recommender is risk reduction across heterogeneous workloads without relying on clairvoyance. |

| **CLM-05** | Recommender inference latency is negligible compared to simulated makespan (H5 supported). | 1,000 repeated prediction latency measurements using `perf_counter_ns`. | `models/model_metadata.json` | None. | High; Median inference latency is 88.2 µs (0.088 ms), well below the 1.0 ms ceiling specified in H5. |
